# 文献摄入配置

将本文件复制为 `paper-vault/paper-intake-config.md`，然后直接修改各项冒号后的内容。
`paper-vault/paper-intake-config.md` 是个人配置，不会被 Git 跟踪。`未指定` 表示不限制。

## 每次运行数量

- 候选文献数：3
- 自动生成论文笔记数：1

## 临时引导

在这里随手添加、修改或删除短期兴趣。每一项可以是一句话、论文标题、链接、
仓库中的 citekey，或你刚读完某篇论文后想继续追踪的问题。`未指定` 表示
本次没有临时引导。

- 我刚读完一篇推理服务论文，本次优先关注它的动态批处理与尾延迟权衡。
- 补充一篇能解释该方向早期技术脉络的经典系统论文。

## 研究偏好

- 长期研究方向：分布式系统与 AI 基础设施
- 当前关注问题：大模型推理服务中的资源调度与性能优化
- 偏好的论文类型：优先系统设计、实现和真实负载评测，弱化纯模型结构或训练算法
- 经典与前沿的比例：经典基础文献约三分之一，近三年的前沿工作约三分之二
- 偏好的会议或期刊：尽量优先国际主流会议和期刊；质量相近时优先 CCF-A
- 希望避开的会议或期刊：未指定
- 明确排除的文献：未指定
- 偏好的方法、系统或应用场景：推理服务、调度、资源管理、运行时和系统评测
- 希望避开的方法或假设：缺少实现或真实系统证据的纯概念方案
- 时间范围：未指定
- 其他要求：推荐理由需要说明与仓库已有论文的关系，不要重复推荐已经生成正式笔记的论文

- 保存推荐记录：是

要求、明确指定的专题文档和这里的临时引导，都会覆盖与其冲突的长期偏好。
